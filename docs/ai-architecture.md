# CoachingOS AI Architecture & Safety Protocols

## 1. Grounded Institute Copilot
- **Deterministic Routing:** User natural-language queries compile into pre-validated analytical views (e.g. attendance drop-offs, fee defaulters, admission pipelines).
- **Lineage & Provenance:** Every response returned to the client attaches exact entity citations and underlying record counts.
- **Uncertainty Guardrail:** If data coverage is below 70%, the copilot explicitly declines to guess, preserving user trust.

## 2. Teacher Worksheet Studio
- Ingests topic and difficulty weighting (Easy, Medium, Hard).
- Outputs valid LaTeX math equations and step-by-step solutions formatted for instant A4 printable export.
- Teachers maintain editorial approval before questions are assigned or added to question banks.

## 3. 24/7 Socratic STEM Tutor
- Guides students through problems using questions and hints without revealing raw answers.
- Moderates non-academic or inappropriate prompts.
